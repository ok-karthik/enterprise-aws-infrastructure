🛡️ Four Governance Gates

Every pull request must pass four independent gates: multi-root formatting and linting, unified Checkov HCL and plan JSON security analysis, custom OPA/Rego tag and instance rules, and Infracost budget analysis.

🔒 Checksum-Sealed Saved Plans

The pipeline avoids apply-time drift by generating binary plans (tfplan.bin) during the PR phase, signing them with SHA256SUMS, and strictly executing the pre-reviewed binary file on merge to main.
