QUALITY FLYWHEEL & SRE RELIABILITY

3-Tier Feedback Loops Architecture

The platform enforces concentric quality rings: Inner loop (instant local validation and hook ceilings), Middle loop (CI plan scoping, governance gates, and autonomous healing), and Outer loop (production drift detection and SLO error budget controls).

← Back to Visualizer Portal

⚡ The Inner Loop (Local Laptop)

Developers and AI coding agents get immediate feedback within 10–15 seconds via make verify-module MODULE=<category/name> without requiring AWS credentials or network calls. Destructive commands are blocked client-side by guard.py.

make verify-module MODULE=storage/s3

🛡️ The Middle Loop (CI Pull Request)

GitHub Actions restricts execution to modified stacks using plan_scope.py. Plan JSON files undergo Checkov and OPA/Conftest security validation. If transient failures occur, healer_runner.py attempts automated remediation up to a hard 3-commit ceiling.

python3 workloads-live-repo/scripts/plan_scope.py

📈 The Outer Loop (Production SRE)

The platform measures live health via CloudWatch Observability Access Manager (OAM), Cost and Usage Reports (CUR 2.0), and platform_slo.json. If the change failure rate breaches SLO limits, agent autonomy is automatically dialed back.

docs/SLO.md & iac-agents-repo/metrics/platform_slo.json
