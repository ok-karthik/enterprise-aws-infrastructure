Multi-Account AWS & Active-Passive DR

Multi-account architecture governed by AWS Organizations OUs, hub-and-spoke Transit Gateway, central inspection Network Firewall, central VPC interface endpoints, and cross-region warm standby disaster recovery.

🌐 Central Network Hub & Firewall

Outbound internet egress is routed through AWS Network Firewall inside network-hub. Dedicated route tables in Transit Gateway enforce tenant network boundaries without cross-tenant VPC peering.

🚨 Active-Passive Disaster Recovery

The platform provisions a standby stack in eu-west-1 with node groups scaled to zero. Aurora Global Database provides sub-second RPO, and Route 53 DNS failover diverts traffic on primary region outage.

🔑 Zero-Key OIDC Architecture

No static AWS credentials exist anywhere. GitHub Actions authenticates through AWS IAM OIDC directly into github-actions-plan (read-only) and github-actions-apply roles bounded by explicit permission ceilings.
