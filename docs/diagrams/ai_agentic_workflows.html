AI Agentic Workflows Architecture

Autonomous coding agents operate within deterministic boundary layers: local quote-aware safety hooks (`guard.py`), collaborator-gated ChatOps scaffolding, and autonomous CI/CD healers with hard retry ceilings.

🛡️ Local Pre-Bash & Pre-Edit Guardrails

The .claude/hooks/guard.py hook intercepts all commands run by AI agents before execution. Destructive verbs (apply, destroy, import, state rm/mv) and protected files defining compliance (.checkov.yaml, policy-library-repo/) are blocked instantly with exit code 2.

python3 .claude/hooks/guard.py pre-bash

🔄 Autonomous Healer Retry Limits

The autonomous pipeline healer automatically analyzes CI failures and attempts fixes. Under healer_guards.py, it refuses to touch the main branch, requires an active PR, enforces a strict 3-commit maximum ceiling, and restores iac-agents-repo/ before committing.

iac-agents-repo/ci_healer/healer_guards.py

📊 Measurable DORA & AI Impact

All PRs generated by ChatOps and the pipeline healer receive the ai-generated label. delivery_metrics.py parses repository metadata to measure change failure rates, deployment frequency, and lead times with sample-size confidence intervals.

python3 .github/scripts/delivery_metrics.py
